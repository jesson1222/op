# Multi Search Engine - 多引擎融合搜索

## 🎯 核心功能

**并行搜索多个引擎** → **RRF 算法融合** → **智能去重** → **高质量结果**

### 为什么需要多引擎搜索？

| 单一引擎 | 多引擎融合 |
|----------|------------|
| 覆盖率有限 | 覆盖率 >95% |
| 算法偏见 | 多源平衡 |
| 可能遗漏 | 全面覆盖 |
| 响应慢 | 并行加速 |

## 🏗️ 架构组件

```
用户查询
    ↓
查询解析器 (解析意图、关键词、过滤器)
    ↓
并行分发 → [Google] [Bing] [DuckDuckGo] [百度]
    ↓
结果收集器 (标准化格式)
    ↓
RRF 融合引擎 (Reciprocal Rank Fusion)
    ↓
去重模块 (URL + 内容相似度)
    ↓
最终排序 → 返回 Top K 结果
```

---

## 📊 融合算法

### RRF (Reciprocal Rank Fusion) - 默认算法

```python
Score = Σ 1 / (k + rank), k=60
```

**优势**：
- ✅ 不依赖具体分数，只看排名
- ✅ 对各引擎公平
- ✅ 被多个引擎同时排前的结果得分高
- ✅ 鲁棒性强

### Borda Count

```python
分数 = Σ (总结果数 - 排名)
```

### 加权位置融合

```python
分数 = Σ (引擎权重 / 排名)
```

## 🛠️ 使用方式

### 基础搜索

```
搜索 "Python asyncio 最佳实践"
```

**执行步骤**：
1. 解析查询关键词
2. 选择默认引擎（Google + Bing + DuckDuckGo）
3. 并行发送查询
4. 融合结果（RRF）
5. 去重并排序
6. 返回 Top 10 结果

### 指定引擎

```
用 Google 和 Bing 搜索 "机器学习教程"
```

### 限定数量

```
搜索 "AI 新闻"，只要前 5 条
```

### 深度搜索

```
深度搜索 "量子计算最新进展"
```

**深度模式**：
- 增加引擎数量（+ 百度 + 学术搜索）
- 增加每引擎结果数（20→50）
- 启用时间过滤（最近 7 天）

## ⚙️ 配置选项

### 引擎选择

```yaml
engines:
  - google        # 默认启用
  - bing          # 默认启用
  - duckduckgo    # 默认启用
  - baidu         # 可选
  - scholar       # 学术搜索
  - news          # 新闻搜索
```

### 结果数量

```yaml
top_k: 10         # 默认返回 10 条
max_per_engine: 20 # 每引擎最多 20 条
```

### RRF 参数

```yaml
rrf_k: 60         # RRF 公式中的 k 值
```

### 去重配置

```yaml
dedup:
  enabled: true
  threshold: 0.9   # 内容相似度阈值
  by_domain: true  # 按域名去重
```

## 🎯 最佳实践

### 1. 查询优化

**❌ 太宽泛**：
```
搜索 "AI"
```

**✅ 具体明确**：
```
搜索 "2026 年 AI 在医疗领域的最新应用"
```

### 2. 引擎选择

**通用搜索**：Google + Bing + DuckDuckGo

**学术研究**：+ Google Scholar + arXiv

**中文内容**：+ 百度

**新闻时效**：启用新闻过滤（最近 7 天）

### 3. 结果评估

**高质量信号**：
- ✅ 被多个引擎同时排前
- ✅ RRF 分数 > 0.03
- ✅ 来自权威域名 (.edu, .gov, 知名公司)
- ✅ 内容新鲜（最近 1 年）

**低质量信号**：
- ❌ 仅单一引擎排名高
- ❌ 域名陌生
- ❌ 内容过时 (>3 年)
- ❌ 明显 SEO 优化痕迹

## ⚠️ 注意事项

### 1. API 限制

- Google Custom Search: 100 次/天（免费）
- Bing Search API: 1000 次/月（免费）
- 建议：缓存高频查询结果

### 2. 结果时效性

- 启用时间过滤获取最新信息
- 注意搜索结果的索引时间
- 重要信息验证多个来源

### 3. 地域差异

- 不同地区搜索结果可能不同
- 中文内容优先百度
- 英文内容优先 Google

## 🎯 故障排除

### 问题 1: 响应慢

**原因**：某个引擎超时
**解决**：启用超时设置（3 秒），跳过慢引擎

### 问题 2: 结果质量差

**原因**：查询太宽泛
**解决**：建议用户细化查询关键词

### 问题 3: 融合效果不好

**原因**：RRF 参数 k 不合适
**解决**：调整 k 值（默认 60，可试 30-100）
