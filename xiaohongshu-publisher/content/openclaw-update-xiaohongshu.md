兄弟们，OpenClaw 又更新了！
这次 v2026.3.8 版本，我连夜测试完，必须来分享一下👇

---

## 🔥 最爽的三个更新

### 1. 终于能备份了！！
之前最怕的就是配置搞丢了
现在一条命令搞定：
```
openclaw backup create
```
手残党福音，升级前必备份✅

### 2. 语音对话能调超时了
之前说话停顿短了发不出去
现在可以自己设 `silenceTimeoutMs`
我设的 2 秒，刚刚好👌

### 3. TUI 自动识别工作区
不用手动配 agent 了
进项目目录直接开用
这个真的省事儿！

## 📦 其他更新速览

- macOS 远程网关 Token 保护（不容易误覆盖了）
- Brave 搜索升级（带来源摘要，更准了）
- version 显示 commit hash（排查问题方便）
- ACP 溯源功能（调试神器）
- 备份命名优化（按日期排序）

---

## 🚀 升级步骤

```bash
# 1. 先备份（重要！）
openclaw backup create

# 2. 升级
npm install -g openclaw@latest

# 3. 查看版本
openclaw --version
```

全程 2 分钟搞定⏱️
