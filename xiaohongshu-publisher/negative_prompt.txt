# 反向提示词 (Negative Prompt)

## 通用低质量元素
```
ugly, deformed, blurry, low quality, distorted, watermark, signature, text, username, logo, brand name, cropped, out of frame, cut off, poorly drawn, amateur, messy, cluttered
```

## 光影问题
```
overexposed, underexposed, bad lighting, harsh shadows, flat lighting, unnatural lighting, noise, grainy, artifacts, compression artifacts
```

## 结构问题
```
disfigured, mutated, extra limbs, missing parts, floating objects, wrong perspective, unrealistic, cartoon, 3d render, cgi, plastic, fake
```

## 颜色问题
```
washed out colors, oversaturated, wrong colors, color cast, banding, posterization, dull, muddy colors
```

## 细节问题
```
low resolution, pixelated, soft focus, out of focus, motion blur, depth of field, bokeh, tilt shift
```

---

## 完整反向提示词 (推荐)

```
ugly, deformed, blurry, low quality, distorted, watermark, signature, text, username, logo, brand name, cropped, out of frame, cut off, poorly drawn, amateur, messy, cluttered, overexposed, underexposed, bad lighting, harsh shadows, noise, grainy, artifacts, disfigured, mutated, wrong perspective, unrealistic, cartoon, 3d render, cgi, plastic, fake, washed out colors, oversaturated, wrong colors, low resolution, pixelated, soft focus, out of focus, motion blur
```
