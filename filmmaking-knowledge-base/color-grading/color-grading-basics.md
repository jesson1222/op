# 色彩分级基础

## 一级调色 vs 二级调色

### 一级调色（Primary Color Grading）
- **作用**：调整整个画面的整体色彩平衡
- **工具**：Lift、Gamma、Gain（阴影、中间调、高光）
- **目标**：校正曝光、白平衡、整体色调
- **应用场景**：素材标准化、基础色彩修正

### 二级调色（Secondary Color Grading）
- **作用**：针对特定颜色范围或区域进行调整
- **工具**：HSL Qualifier、Power Window、跟踪
- **目标**：突出主体、创造氛围、修复局部问题
- **应用场景**：肤色优化、天空调色、品牌色强调

## 色彩空间理解

### 常见色彩空间
| 色彩空间 | 特点 | 应用场景 |
|----------|------|----------|
| **Rec.709** | 标准高清电视色彩 | 网络视频、电视播出 |
| **Rec.2020** | 超高清广色域 | 4K/8K HDR 内容 |
| **Log** | 扁平化曲线，保留动态范围 | 专业摄影机原始素材 |
| **sRGB** | 标准网络色彩 | 网页、社交媒体 |

### Log 素材处理流程
1. **应用 LUT**：将 Log 转换为标准色彩空间
2. **一级调色**：调整整体曝光和对比度
3. **二级调色**：精细化调整特定元素
4. **输出设置**：根据目标平台选择输出色彩空间

## 示波器使用

### 波形图（Waveform）
- **功能**：显示亮度分布（0-100 IRE）
- **用途**：
  - 检查曝光是否合适
  - 确保高光不过曝（<100 IRE）
  - 确保阴影有细节（>0 IRE）

### 矢量图（Vectorscope）
- **功能**：显示色彩饱和度和色相
- **用途**：
  - 检查肤色是否准确（落在肤色线附近）
  - 控制色彩饱和度
  - 确保色彩一致性

### 直方图（Histogram）
- **功能**：显示像素亮度分布
- **用途**：
  - 快速判断整体曝光
  - 识别过曝或欠曝区域

## 色彩理论应用

### 色彩心理学
- **暖色调**（红、橙、黄）：热情、活力、温暖
- **冷色调**（蓝、绿、紫）：冷静、专业、神秘
- **中性色**（灰、白、黑）：简约、高级、现代

### 色彩搭配原则
1. **互补色**：相对色轮位置，产生强烈对比
2. **类似色**：相邻色轮位置，和谐统一
3. **三角色**：等距三角形，丰富而平衡
4. **单色调**：同一色相不同明度，简洁优雅

## 肤色保护技巧

### 肤色范围识别
- **亚洲肤色**：偏黄/红，色相角约 15-30°
- **欧美肤色**：偏粉/橙，色相角约 20-40°
- **非洲肤色**：偏棕/红，色相角约 10-25°

### 保护方法
1. **使用 Power Window**：单独保护肤色区域
2. **HSL Qualifier**：精确选择肤色范围
3. **跟踪功能**：自动跟随主体移动
4. **饱和度控制**：避免肤色过度饱和

## 实际调色工作流

### 电影级调色流程
1. **素材整理**：统一命名，创建代理文件
2. **一级校正**：曝光、白平衡、对比度
3. **风格创建**：应用创意 LUT 或手动调色
4. **二级调整**：精细优化关键元素
5. **一致性检查**：确保镜头间色彩匹配
6. **输出交付**：按平台要求导出

### 快速调色技巧
- **使用预设**：节省时间，保持风格一致
- **参考图像**：导入参考图进行色彩匹配
- **分层调色**：分别处理阴影、中间调、高光
- **定期休息**：避免眼睛疲劳导致判断失误

> **提示**：调色不仅是技术活，更是艺术创作。多观察优秀作品的色彩运用，培养自己的色彩敏感度。
