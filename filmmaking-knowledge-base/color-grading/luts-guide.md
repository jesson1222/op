# LUTs 使用指南

## LUT 基础概念

### 什么是 LUT？
- **LUT**（Look-Up Table）是色彩查找表
- 将输入颜色值映射到输出颜色值
- 用于快速应用预设的色彩风格

### LUT 类型区分

#### 技术 LUT（Technical LUT）
- **用途**：色彩空间转换、Log 转 Rec.709
- **特点**：精确、无创意处理
- **使用场景**：素材解码、监看校准

#### 创意 LUT（Creative LUT）
- **用途**：应用特定视觉风格
- **特点**：包含艺术化色彩处理
- **使用场景**：风格化调色、快速预览

## LUT 应用层级

### 1. 输入 LUT（Input LUT）
- **位置**：素材导入时应用
- **作用**：将 Log 素材转换为可编辑色彩空间
- **注意事项**：影响后续所有调色操作

### 2. 输出 LUT（Output LUT）
- **位置**：最终输出时应用
- **作用**：确保在特定显示设备上正确显示
- **注意事项**：不影响编辑过程

### 3. 创意 LUT（Creative LUT）
- **位置**：调色节点中应用
- **作用**：快速实现特定视觉风格
- **最佳实践**：作为起点，后续微调

## LUT 强度调整

### DaVinci Resolve 中的 LUT 强度
```
节点 → 右键 → LUT → 调整强度滑块
```

### Premiere Pro 中的 LUT 强度
```
效果控件 → Lumetri Color → Look → 强度滑块
```

### 强度调整建议
- **100%**：完整应用 LUT 效果
- **50-70%**：保留原始素材特性，轻微风格化
- **30% 以下**：仅作为参考，主要依靠手动调色

## 不同场景 LUT 选择

### 电影感 LUT
- **特点**：低对比、柔和色调、胶片颗粒
- **适用**：剧情片、文艺片、MV
- **推荐**：FilmConvert、Dehancer、CineStyle

### 商业广告 LUT
- **特点**：高饱和、锐利对比、鲜艳色彩
- **适用**：产品广告、宣传片、商业视频
- **推荐**：Color Grading Central、Lutify.me

### 纪录片 LUT
- **特点**：自然真实、轻微增强、保持原始感
- **适用**：纪录片、新闻、纪实摄影
- **推荐**：Documentary LUTs、Natural Looks

### 音乐视频 LUT
- **特点**：高对比、创意色彩、强烈风格
- **适用**：MV、舞蹈视频、创意短片
- **推荐**：Music Video LUTs、Stylized Packs

## 自定义 LUT 制作

### 从调色创建 LUT
**DaVinci Resolve 步骤：**
1. 完成调色后，右键点击节点
2. 选择 "Generate LUT"
3. 保存为 .cube 格式
4. 可在其他项目中复用

### LUT 格式兼容性
- **.cube**：通用格式，支持大多数软件
- **.3dl**：DaVinci Resolve 原生格式
- **.lut**：部分软件专用格式

## LUT 使用最佳实践

### ✅ 推荐做法
- **先应用技术 LUT**，再进行创意调色
- **保存原始素材**，LUT 作为非破坏性处理
- **测试不同 LUT**，选择最适合项目的风格
- **微调 LUT 效果**，不要完全依赖预设

### ❌ 避免做法
- **直接在 Log 素材上应用创意 LUT**
- **过度依赖 LUT**，忽略基础调色技能
- **使用不匹配的 LUT**（如为 S-Log3 设计的 LUT 用于 C-Log）
- **忽视色彩一致性**，同一项目使用过多不同 LUT

## 常用 LUT 资源

### 免费资源
- **ARRI LUT Generator**：官方 ARRI Log 转换 LUT
- **RED LUTs**：RED 官方色彩转换 LUT
- **FilmConvert Free LUTs**：基础电影感 LUT

### 付费资源
- **Dehancer**：专业级胶片模拟 LUT
- **Color Grading Central**：多样化创意 LUT
- **Lutify.me**：高质量商业 LUT 包
- **IWLTBAP**：电影级 LUT 合集

> **提示**：LUT 是强大的工具，但不是万能的。最好的调色师会将 LUT 作为起点，然后根据具体素材和创意需求进行精细调整。
