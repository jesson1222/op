# 飞书知识库导入指南

## 📋 导入步骤

### 第一步：在飞书中创建知识库
1. 打开飞书应用
2. 点击左侧导航栏的「知识库」图标
3. 点击右上角的「+ 创建」按钮
4. 选择「新建知识库」
5. 输入名称：**"影视制作知识库"**
6. 选择可见范围（建议选择团队可见）
7. 点击「创建」

### 第二步：创建目录结构
按照以下结构在飞书中创建页面和子页面：

```
🎬 影视制作知识库/
├── 📸 摄影基础/
│   ├── 相机设置与参数
│   ├── 镜头选择指南  
│   ├── 光线与曝光控制
│   └── 构图与取景技巧
│
├── 🎥 专业拍摄/
│   ├── 电影感拍摄技巧
│   ├── 灯光布置方案
│   └── 稳定器与运镜
│
├── ✂️ 后期剪辑/
│   ├── 剪辑软件教程

│   └── 转场与特效运用

│   ├── 色彩分级基础
```

### 第三步：复制内容到对应页面

#### 方法一：逐个页面复制
1. 在本地文件夹中打开对应的 `.md` 文件
2. 复制全部内容
3. 在飞书知识库中找到对应的页面
4. 粘贴内容（飞书会自动转换 Markdown 格式）

#### 方法二：批量导入（推荐）
1. 将所有 `.md` 文件按目录结构整理好
2. 使用飞书的批量导入功能（如果可用）
3. 或者使用飞书 API 进行程序化导入

### 第四步：格式优化
- **检查图片链接**：本地图片需要上传到飞书
- **调整表格格式**：确保表格在飞书中显示正常
- **验证链接有效性**：确保所有外部链接可访问
- **添加标签和分类**：便于搜索和管理

## 💡 使用建议

### 搜索优化
- 在每个页面的开头添加关键词标签
- 使用一致的术语和命名规范
- 创建索引页面便于快速导航

### 定期更新
- 设置每月内容审核提醒
- 跟踪新技术和工具更新
- 收集团队反馈持续改进

### 权限管理
- 设置适当的编辑权限
- 为不同团队成员分配维护责任
- 保留版本历史便于回溯
