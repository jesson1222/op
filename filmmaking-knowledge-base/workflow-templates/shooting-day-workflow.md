# 拍摄日工作流程

## 开机检查流程

### 设备状态确认
- [ ] 相机电池电量充足（建议备用电池）
- [ ] 存储卡空间足够且格式化完成
- [ ] 镜头清洁无污渍
- [ ] 稳定器电量和校准状态
- [ ] 音频设备电池和存储空间
- [ ] 灯光设备电量和配件齐全

### 相机设置验证
- [ ] 拍摄格式正确（ProRes 422 HQ / RAW / H.264）
- [ ] 分辨率和帧率符合项目要求
- [ ] 白平衡设置准确（手动或预设）
- [ ] ISO/快门/光圈初始设置合理
- [ ] 对焦模式选择正确（手动/自动/跟踪）
- [ ] 音频输入电平和通道设置

### 场景准备
- [ ] 拍摄许可和场地确认
- [ ] 团队成员到位和分工明确
- [ ] 演员/模特状态准备就绪
- [ ] 道具和服装检查完毕
- [ ] 备用方案和应急预案确认

## 素材备份策略

### 实时备份原则
- **双卡录制**：主卡+备份卡同时录制
- **现场备份**：每完成一个场景立即备份到移动硬盘
- **云同步**：重要素材上传到云端（如适用）

### 备份文件命名规范
```
项目名称_场景编号_镜头编号_拍摄日期_版本号
Example: Wedding_01_001_20260304_v1
```

### 备份验证步骤
1. **文件完整性检查**：确保文件可以正常播放
2. **元数据核对**：确认时间码、场记信息完整
3. **多副本存储**：至少保持2个备份副本
4. **备份日志记录**：记录备份时间和位置

## 现场问题处理

### 常见技术问题
| 问题 | 快速解决方案 |
|------|-------------|
| 电池耗尽 | 立即更换备用电池，标记耗尽电池 |
| 存储卡满 | 更换新卡，立即备份已拍素材 |
| 对焦失灵 | 切换到手动对焦，使用峰值对焦 |
| 曝光异常 | 使用斑马纹或直方图调整 |
| 音频中断 | 检查连接线，切换备用录音设备 |

### 环境突发情况
- **天气变化**：准备防雨/防晒设备，调整拍摄计划
- **光线变化**：快速调整白平衡和曝光补偿
- **噪音干扰**：暂停拍摄，寻找安静时段或地点
- **人员变动**：灵活调整拍摄顺序，优先关键镜头

## 日志记录模板

### 拍摄日志基本信息
- **日期**：YYYY-MM-DD
- **地点**：具体地址
- **天气**：晴/阴/雨，温度
- **团队成员**：摄影师、助理、灯光师等
- **设备清单**：相机型号、镜头、灯光、音频等

### 镜头记录表
| 场景 | 镜头 | 内容描述 | 时长 | 备注 |
|------|------|----------|------|------|
| 01 | 001 | 主角特写 | 00:30 | 良好 |
| 01 | 002 | 全景环境 | 00:45 | 需重拍 |

### 问题记录
- **技术问题**：详细描述问题和解决方案
- **创意调整**：导演/客户的要求变更
- **时间延误**：原因和影响评估
- **素材质量**：需要重拍的镜头清单
