# 项目交付标准

## 文件命名规范

### 基本命名规则
- **项目名称_版本_日期_描述.扩展名**
- **示例**：`Wedding_JohnMary_v2_20260304_Final.mp4`

### 版本控制
- **v1, v2, v3...**：主要版本迭代
- **a, b, c...**：小修改版本
- **Final**：最终交付版本
- **Master**：母版文件

### 文件夹结构
```
Project_Name/
├── 01_Raw_Footage/
├── 02_Edited_Sequences/
├── 03_Color_Grading/
├── 04_Audio_Mixing/
├── 05_Graphics_Titles/
├── 06_Deliverables/
└── 07_Archives/
```

## 交付格式要求

### 视频格式
| 用途 | 格式 | 分辨率 | 帧率 | 编码 | 比特率 |
|------|------|--------|------|------|--------|
| 网络发布 | MP4 | 1920x1080 | 24/30fps | H.264 | 10-15 Mbps |
| 高质量网络 | MP4 | 3840x2160 | 24/30fps | H.265 | 25-50 Mbps |
| 广播电视 | MOV | 1920x1080 | 25/30fps | ProRes 422 | 147 Mbps |
| 电影放映 | MXF | 4096x2160 | 24fps | DNxHR HQX | 1750 Mbps |
| 存档母版 | MOV | 原始分辨率 | 原始帧率 | ProRes 4444 | 无损 |

### 音频格式
- **立体声**：48kHz, 24bit WAV/AIFF
- **5.1环绕声**：48kHz, 24bit WAV (6通道)
- **网络音频**：AAC 320kbps 或更高

### 色彩空间
- **SDR交付**：Rec.709, Gamma 2.4
- **HDR交付**：Rec.2020, PQ 或 HLG
- **Log素材**：提供原始Log + 调色版本

## 客户验收清单

### 技术验收
- [ ] 视频无技术问题（卡顿、掉帧、噪点等）
- [ ] 音频同步准确，无爆音或失真
- [ ] 色彩一致性良好，无色偏
- [ ] 字幕时间轴准确，内容正确
- [ ] 输出格式符合要求
- [ ] 文件大小合理，传输正常

### 创意验收
- [ ] 整体风格符合预期
- [ ] 剪辑节奏合适
- [ ] 调色效果满意
- [ ] 音乐和音效配合良好
- [ ] 图形和文字设计符合品牌
- [ ] 故事叙述清晰有效

### 法律合规
- [ ] 所有素材版权已获得授权
- [ ] 音乐使用许可证齐全
- [ ] 人物肖像权已获得同意
- [ ] 商标和品牌使用合规
- [ ] 敏感内容已处理

## 项目归档流程

### 归档内容
1. **原始素材**（RAW/Log格式）
2. **工程文件**（所有软件的项目文件）
3. **中间文件**（调色LUTs、特效预设等）
4. **最终交付文件**（所有格式版本）
5. **文档资料**（拍摄计划、客户反馈、修改记录）

### 存储策略
- **本地存储**：至少保留2个副本
- **云存储**：重要项目上传到云备份
- **离线存储**：长期项目使用LTO磁带或硬盘
- **元数据**：详细记录项目信息和关键词

### 归档命名
- **项目名称_归档日期_版本号**
- **包含README文件说明内容结构**
- **包含联系人信息和访问权限**

## 质量保证流程

### 最终检查清单
- [ ] 在不同设备上预览（手机、平板、电脑、电视）
- [ ] 在不同环境下测试（明亮、昏暗环境）
- [ ] 邀请第三方进行客观评审
- [ ] 进行最终技术检测（使用专业工具）
- [ ] 确认所有交付要求都已满足
- [ ] 准备备用交付方案

### 应急预案
- **文件损坏**：准备多个备份副本
- **格式不兼容**：准备多种格式版本
- **客户不满意**：预留修改时间和预算
- **传输失败**：准备多种传输方式（网盘、硬盘、邮寄）

> **重要提示**：交付不是终点，而是新合作的开始。确保客户完全满意，并为未来合作奠定基础。
