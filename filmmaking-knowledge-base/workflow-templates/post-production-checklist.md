# 后期制作检查表

## 素材整理规范

### 文件夹结构
```
项目名称/
├── RAW/                # 原始素材
├── EDITED/             # 剪辑后素材  
├── GRADED/             # 调色后素材
├── AUDIO/              # 音频文件
├── GRAPHICS/           # 图形元素
├── EXPORTS/            # 输出文件
└── PROJECTS/           # 项目工程文件
```

### 文件命名规范
- **原始素材**：`YYYYMMDD_Scene_Take_Camera.ext`
  - 示例：`20260304_Interview_Take01_A7S3.MP4`
- **剪辑版本**：`ProjectName_v01_EditDate.ext`
- **调色版本**：`ProjectName_v01_GradeDate.ext`
- **最终输出**：`ClientName_ProjectName_Final_Date.ext`

### 备份策略
- **三重备份原则**：原始素材 + 工作副本 + 云备份
- **校验完整性**：使用校验和工具验证文件完整性
- **元数据保留**：确保时间码、音频同步信息完整

## 剪辑质量检查

### 技术检查项
- [ ] **同步检查**：音视频同步准确（±1帧内）
- [ ] **连续性**：动作、视线、位置连续无跳跃
- [ ] **音频电平**：对话 -6dB 到 -3dB，峰值不超过 -1dB
- [ ] **剪辑点**：避免在动作中间硬切
- [ ] **节奏控制**：符合内容情绪和节奏需求

### 内容检查项
- [ ] **故事完整性**：叙事逻辑清晰，无信息缺失
- [ ] **情感表达**：通过剪辑强化情感冲击
- [ ] **品牌一致性**：符合客户品牌调性和要求
- [ ] **目标受众**：内容适合目标观众理解
- [ ] **时长控制**：符合平台或客户时长要求

### 软件特定检查
#### DaVinci Resolve
- [ ] **媒体池组织**：素材分类清晰
- [ ] **时间线优化**：删除未使用素材
- [ ] **渲染设置**：选择正确输出格式和编码
- [ ] **代理媒体**：确认使用合适代理级别

#### Premiere Pro
- [ ] **序列设置**：匹配主素材格式
- [ ] **效果控件**：关键帧平滑无跳变
- [ ] **动态链接**：After Effects 项目正常链接
- [ ] **缓存清理**：定期清理媒体缓存

## 调色一致性验证

### 技术验证
- [ ] **色彩空间**：确认工作色彩空间正确
- [ ] **示波器检查**：
  - 波形图：亮度范围合理（0-100 IRE）
  - 矢量图：肤色落在正确区域
  - 直方图：无严重裁剪
- [ ] **白平衡**：中性灰区域确实中性
- [ ] **曝光**：高光和阴影细节保留适当

### 风格一致性
- [ ] **场景间一致性**：同一场景不同镜头色彩匹配
- [ ] **时间线一致性**：整个项目色调统一
- [ ] **参考对比**：与参考影片或客户要求一致
- [ ] **多设备预览**：在不同显示器上检查效果

### 输出验证
- [ ] **LUT 应用**：技术 LUT 正确应用到输出
- [ ] **色彩管理**：输出色彩空间正确转换
- [ ] **HDR/SDR**：根据交付要求正确处理
- [ ] **广播安全**：符合广播色彩和亮度标准

## 音频质量审核

### 技术指标
- [ ] **采样率**：48kHz（视频标准）
- [ ] **位深度**：24-bit 或更高
- [ ] **声道配置**：立体声或 5.1 根据需求
- [ ] **噪声水平**：背景噪声控制在可接受范围
- [ ] **动态范围**：对话清晰，音乐和音效平衡

### 内容质量
- [ ] **清晰度**：人声清晰可懂
- [ ] **一致性**：不同录音片段音质匹配
- [ ] **混音平衡**：对话、音乐、音效比例合适
- [ ] **空间感**：立体声场自然合理
- [ ] **情感配合**：音频增强画面情感表达

### 专业处理
- [ ] **降噪处理**：必要时进行专业降噪
- [ ] **均衡调整**：优化频率响应
- [ ] **压缩限制**：控制动态范围，避免失真
- [ ] **混响添加**：根据场景添加适当空间感

## 输出格式确认

### 视频格式
- [ ] **分辨率**：1080p, 4K, 8K 根据需求
- [ ] **帧率**：24fps, 25fps, 30fps, 60fps 匹配源素材
- [ ] **编码格式**：H.264, H.265, ProRes, DNxHD
- [ ] **比特率**：根据用途选择合适比特率
- [ ] **容器格式**：MP4, MOV, MXF

### 音频格式
- [ ] **音频编码**：AAC, PCM, AC3
- [ ] **音频比特率**：192kbps, 320kbps, 无损
- [ ] **采样率**：48kHz（视频），44.1kHz（音频）
- [ ] **声道数**：单声道、立体声、5.1、7.1

### 平台特定要求
#### YouTube
- [ ] **推荐格式**：MP4 (H.264 + AAC)
- [ ] **最大分辨率**：8K (7680×4320)
- [ ] **最大帧率**：60fps
- [ ] **文件大小**：≤128GB 或 ≤12小时

#### Instagram
- [ ] **正方形**：1080×1080 (1:1)
- [ ] **竖屏**：1080×1350 (4:5)
- [ ] **横屏**：1080×608 (16:9)
- [ ] **最大时长**：60秒（普通），60分钟（IGTV）

#### TikTok
- [ ] **竖屏格式**：1080×1920 (9:16)
- [ ] **最大时长**：10分钟
- [ ] **推荐编码**：H.264
- [ ] **音频**：AAC, 44.1kHz
