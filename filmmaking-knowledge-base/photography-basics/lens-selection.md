# 镜头选择指南

## 焦距选择原则

### 广角镜头（16-35mm）
- **适用场景**：环境摄影、建筑摄影、创意变形效果
- **视觉特点**：强调透视感，扩大空间感
- **注意事项**：边缘畸变控制，避免重要元素放在画面边缘

### 标准镜头（35-85mm）
- **适用场景**：人像摄影、日常记录、自然视角
- **视觉特点**：接近人眼视角，自然真实
- **推荐焦段**：50mm（全能）、85mm（人像）

### 长焦镜头（85mm+）
- **适用场景**：远距离拍摄、背景压缩、浅景深效果
- **视觉特点**：压缩空间感，突出主体
- **常用焦段**：85mm、135mm、200mm+

## 镜头类型对比

### 定焦 vs 变焦
| 特性 | 定焦镜头 | 变焦镜头 |
|------|----------|----------|
| 光圈 | 通常更大（f/1.4, f/1.8） | 通常较小（f/2.8, f/4） |
| 画质 | 通常更锐利 | 画质稍逊但足够专业 |
| 灵活性 | 需要移动位置 | 可变焦距，灵活构图 |
| 价格 | 相对便宜 | 相对昂贵 |
| 重量 | 通常较轻 | 通常较重 |

### T值 vs F值
- **F值**：理论光圈值，基于几何光学计算
- **T值**：实际透光率，考虑镜片透光损失
- **电影镜头**：通常标注T值，确保曝光一致性
- **摄影镜头**：通常标注F值

## 镜头呼吸效应处理

### 什么是呼吸效应？
- 对焦时视角发生微小变化的现象
- 在视频拍摄中特别明显

### 解决方案：
1. **选择专为视频设计的镜头**
2. **使用跟焦器减少手动对焦**
3. **后期稳定软件修正**
4. **拍摄时预留额外画面空间**

## 推荐镜头组合

### 入门级三镜头套装
- **广角**：16-35mm f/4
- **标准**：24-70mm f/2.8  
- **长焦**：70-200mm f/2.8

### 电影感定焦套装
- **超广角**：24mm T1.5
- **标准**：35mm T1.5, 50mm T1.5
- **人像**：85mm T1.5

### 预算有限推荐
- **一镜走天下**：24-105mm f/4
- **最佳性价比**：35mm f/1.8 + 85mm f/1.8

## 实际拍摄建议

### 人像拍摄
- **首选**：85mm f/1.4 或 50mm f/1.2
- **全身人像**：35mm 或 24mm
- **特写人像**：135mm

### 风光摄影
- **超广角**：16-24mm
- **中焦段**：24-70mm
- **长焦风光**：70-200mm（压缩山脉、突出细节）

### 视频拍摄
- **电影感**：35mm 或 50mm
- **访谈**：85mm
- **运动跟拍**：24-70mm 变焦

> **提示**：焦距选择没有绝对标准，关键是理解不同焦段的视觉语言，并根据创作意图选择合适的工具。
