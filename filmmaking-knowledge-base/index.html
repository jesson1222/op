📸 摄影基础

相机设置与参数

ISO、快门、光圈三角关系

曝光三角是摄影的基础，三个参数相互影响：

  • ISO：感光度，数值越高噪点越多，但能在暗光环境下拍摄
  • 快门速度：控制曝光时间，高速快门冻结动作，慢速快门创造动态模糊
  • 光圈：控制进光量和景深，大光圈（小f值）产生浅景深，小光圈（大f值）获得大景深

白平衡设置技巧

正确的白平衡确保色彩准确还原：

  • 日光环境：5500K-6500K
  • 阴天环境：6500K-7500K
  • 室内钨丝灯：2800K-3200K
  • 荧光灯：4000K-4500K
  • 建议使用自定义白平衡或灰卡校准

对焦模式选择

  • 单点对焦：精确控制对焦点，适合静态主体
  • 区域对焦：在指定区域内自动选择对焦点，适合中等移动速度的主体
  • 跟踪对焦：持续跟踪移动主体，适合快速运动场景
  • 手动对焦：完全控制，适合视频拍摄或特殊创意需求

拍摄格式选择

  • RAW格式：保留最多图像信息，后期处理空间最大，文件体积大
  • ProRes格式：专业视频编码，画质优秀，文件适中，适合后期制作
  • H.264/H.265：高效压缩，文件小，适合网络分发，后期空间有限

帧率与快门角度设置

视频拍摄中的关键参数：

  • 24fps：电影标准帧率，营造电影感
  • 30fps：电视标准，流畅自然
  • 60fps+：慢动作素材，需要后期降速
  • 快门角度：180°原则（快门速度 = 1/(2×帧率)），如24fps对应1/48s快门

镜头选择指南

焦距选择原则

广角镜头（16-35mm）
  • 适用场景：环境摄影、建筑摄影、创意变形效果
  • 视觉特点：强调透视感，扩大空间感
  • 注意事项：边缘畸变控制，避免重要元素放在画面边缘
标准镜头（35-85mm）
  • 适用场景：人像摄影、日常记录、自然视角
  • 视觉特点：接近人眼视角，自然真实
  • 推荐焦段：50mm（全能）、85mm（人像）
长焦镜头（85mm+）
  • 适用场景：远距离拍摄、背景压缩、浅景深效果
  • 视觉特点：压缩空间感，突出主体
  • 常用焦段：85mm、135mm、200mm+

镜头类型对比

特性 定焦镜头 变焦镜头
光圈 通常更大（f/1.4, f/1.8） 通常较小（f/2.8, f/4）
画质 通常更锐利 画质稍逊但足够专业
灵活性 需要移动位置 可变焦距，灵活构图
价格 相对便宜 相对昂贵
重量 通常较轻 通常较重

T值 vs F值

  • F值：理论光圈值，基于几何光学计算
  • T值：实际透光率，考虑镜片透光损失
  • 电影镜头：通常标注T值，确保曝光一致性
  • 摄影镜头：通常标注F值

镜头呼吸效应处理

什么是呼吸效应？

对焦时视角发生微小变化的现象，在视频拍摄中特别明显。

解决方案：

  • 选择专为视频设计的镜头
  • 使用跟焦器减少手动对焦
  • 后期稳定软件修正
  • 拍摄时预留额外画面空间

推荐镜头组合

入门级三镜头套装

  • 广角：16-35mm f/4
  • 标准：24-70mm f/2.8
  • 长焦：70-200mm f/2.8

电影感定焦套装

  • 超广角：24mm T1.5
  • 标准：35mm T1.5, 50mm T1.5
  • 人像：85mm T1.5

预算有限推荐

  • 一镜走天下：24-105mm f/4
  • 最佳性价比：35mm f/1.8 + 85mm f/1.8
提示：焦距选择没有绝对标准，关键是理解不同焦段的视觉语言，并根据创作意图选择合适的工具。

光线与曝光控制

自然光利用技巧

  • 黄金时刻：日出后和日落前1小时，光线柔和温暖，最适合拍摄
  • 蓝色时刻：日出前和日落后，天空呈现蓝色调，适合城市夜景
  • 阴天光线：天然柔光箱，光线均匀，适合人像和产品拍摄
  • 正午阳光：硬光强烈，通常需要柔化或寻找遮荫

人工光源布置方案

  • 主光源：主要照明，决定整体光影效果
  • 补光：填充阴影，降低对比度
  • 轮廓光：勾勒主体轮廓，增加立体感
  • 背景光：照亮背景，分离主体与背景

测光模式选择

  • 评价测光：全画面平均测光，适合一般场景
  • 中央重点测光：重视画面中央区域，适合人像
  • 点测光：精确测量小区域，适合高对比场景
  • 直方图监控：实时查看曝光分布，避免过曝欠曝

HDR拍摄策略

  • 包围曝光：拍摄多张不同曝光的照片，后期合成HDR
  • Log格式：使用相机Log模式，保留更多动态范围
  • 渐变滤镜：物理方式平衡天空和地面曝光差异
  • 后期处理：使用专业软件进行HDR合成和色调映射

避免过曝和欠曝

  • 使用斑马纹显示过曝区域
  • 开启高光警告功能
  • 适当降低ISO而非提高快门速度
  • 使用ND滤镜控制进光量
  • 后期保留一定的宽容度空间

构图与取景技巧

三分法、黄金分割

  • 将画面分为九宫格，重要元素放在交点或线上
  • 地平线放在上1/3或下1/3位置，避免居中
  • 黄金螺旋构图，引导视线自然流动
  • 保持画面平衡，避免一侧过重

引导线构图

  • 利用道路、河流、建筑线条引导视线到主体
  • 对角线构图增加动感和张力
  • 曲线构图营造柔和流畅的感觉
  • 放射线构图突出中心主体

负空间运用

  • 留白创造呼吸感和神秘感
  • 主体朝向方向预留更多空间
  • 简洁背景突出主体
  • 利用负空间传达情绪和氛围

电影感构图要素

  • 宽画幅：使用2.39:1或16:9比例
  • 浅景深：大光圈创造背景虚化
  • 对称构图：韦斯·安德森风格
  • 框架构图：利用门窗、拱门等自然框架
  • 低角度/高角度：创造戏剧性视角

动态构图原则

  • 运动主体前方预留空间
  • 保持视线方向的一致性
  • 利用前景增加层次感
  • 避免画面切割重要元素
  • 考虑连续镜头的构图连贯性

🎥 专业拍摄

电影感拍摄技巧

宽画幅设置

  • 2.39:1：经典电影宽屏比例，最具电影感
  • 16:9：高清电视标准，通用性强
  • 4:3：复古风格，适合特定题材
  • 拍摄时预留安全区域，后期裁剪更灵活

浅景深控制

  • 使用大光圈镜头（f/1.4-f/2.8）
  • 增加主体与背景的距离
  • 使用长焦镜头增强背景虚化
  • 注意焦点准确性，避免主体失焦

运动镜头设计

  • 推镜头：靠近主体，强调重要性
  • 拉镜头：远离主体，揭示环境
  • 摇镜头：水平或垂直转动，跟随动作
  • 跟拍：平行跟随主体移动
  • 升降镜头：垂直移动，创造震撼效果

色彩搭配原则

  • 互补色：红绿、蓝橙，创造强烈对比
  • 类似色：相邻色相，和谐统一
  • 单色调：同一色相不同明度，简洁高级
  • 避免过多颜色混杂，保持主色调统一

胶片颗粒效果

  • 后期添加适量胶片颗粒增加质感
  • 颗粒强度根据画面内容调整
  • 避免过度使用影响画质
  • 结合色彩分级营造复古氛围

灯光布置方案

三点布光法

  • 主光（Key Light）：主要光源，通常45度角照射主体
  • 补光（Fill Light）：填充阴影，强度为主光的1/2-1/3
  • 轮廓光（Back Light）：从后方照亮主体轮廓，增加立体感
  • 三点布光是基础，可根据需要增减光源

柔光 vs 硬光

  • 柔光特点：光线均匀，阴影柔和，适合人像和产品
  • 硬光特点：对比强烈，阴影清晰，适合戏剧性和力量感
  • 柔光实现：柔光箱、反光伞、柔光布、阴天自然光
  • 硬光实现：直射阳光、裸灯、聚光筒

色温匹配技巧

  • 混合光源时统一色温（通常5600K日光或3200K钨丝灯）
  • 使用CTO（橙色）或CTB（蓝色）滤片调整色温
  • 白平衡设置与主光源匹配
  • 避免色温混乱造成色彩不协调

反光板使用

  • 白色反光板：柔和补光，自然效果
  • 银色反光板：强反射，增加对比度
  • 金色反光板：暖色调补光，适合黄金时刻
  • 黑色反光板：吸收光线，增加阴影
  • 反光板距离控制光线强度

LED灯阵列配置

  • RGBWW LED：可调色温和色彩，功能全面
  • 双色温LED：3200K-5600K连续调节，实用性强
  • 单色温LED：固定色温，成本较低
  • 多灯组合时注意功率和散热
  • 使用DMX控制器统一管理多盏灯具

稳定器与运镜

稳定器校准步骤

  1. 安装相机并初步平衡
  2. 调整前后平衡（俯仰轴）
  3. 调整左右平衡（横滚轴）
  4. 调整上下平衡（偏航轴）
  5. 微调电机力度参数
  6. 测试运行并最终调整

常见运镜手法

推拉镜头
  • 推进：逐渐靠近主体，强调情感或重要细节
  • 拉远：逐渐远离主体，揭示环境或制造疏离感
  • 保持匀速运动，避免突然加速减速
摇镜头
  • 水平摇：跟随水平移动的主体或展示宽广场景
  • 垂直摇：展示高度或从局部到整体
  • 起始和结束要有停顿，避免突兀
跟拍
  • 保持与主体相同的速度和方向
  • 使用滑轨或稳定器确保平稳
  • 注意背景变化，避免干扰主体
升降镜头
  • 从低到高：展现宏伟或希望
  • 从高到低：制造压迫感或揭示细节
  • 需要专业设备如升降臂或无人机

手持稳定技巧

  • 双脚分开与肩同宽，膝盖微屈
  • 肘部贴近身体，减少晃动
  • 使用呼吸控制，屏住呼吸拍摄关键镜头
  • 借助墙壁、栏杆等支撑物
  • 后期使用稳定软件进一步优化

剪辑节奏与叙事

剪辑点选择原则

  • 动作剪辑：在动作过程中切换，保持流畅性
  • 视线剪辑：跟随角色视线方向切换
  • 情绪剪辑：根据情感节奏决定剪辑时机
  • 180度规则：保持空间关系一致性
  • 匹配剪辑：相似形状、动作或色彩的转场

节奏控制技巧

  • 快节奏：短镜头、快速切换，营造紧张感
  • 慢节奏：长镜头、缓慢切换，营造沉思感
  • 节奏变化：根据剧情需要调整节奏
  • 音乐同步：剪辑点与音乐节拍同步
  • 呼吸空间：给观众消化信息的时间

情感表达通过剪辑

  • 镜头长度影响情感强度
  • 剪辑节奏反映角色心理状态
  • 镜头顺序构建叙事逻辑
  • 留白创造悬念和想象空间
  • 对比剪辑强化情感冲突

多机位同步剪辑

  • 使用音频波形自动同步
  • 手动标记同步点
  • 多机位切换面板实时切换
  • 保持主镜头连续性
  • 利用不同角度丰富视觉体验

B-roll 运用策略

  • 覆盖主镜头中的问题片段
  • 提供额外视觉信息
  • 创造视觉节奏变化
  • 避免画面单调
  • 支持叙事主题

转场与特效运用

自然转场 vs 创意转场

  • 硬切：最常用的转场，直接切换
  • 淡入淡出：时间或场景转换
  • 叠化：两个镜头重叠，表示时间流逝
  • 划像：创意转场，需谨慎使用
  • 匹配转场：利用相似元素自然过渡

L-cut 和 J-cut 技巧

  • L-cut：音频先于视频切换，保持对话连续性
  • J-cut：音频晚于视频切换，提前引入新场景声音
  • 增强叙事流畅性
  • 避免生硬的切换
  • 创造声音先行的沉浸感

速度变化处理

  • 时间重映射：精确控制速度变化
  • 速度 ramp：平滑的速度过渡
  • 跳帧效果：创造特殊视觉效果
  • 光流法：高质量慢动作生成
  • 保持动作连贯性

关键帧动画

  • 位置、缩放、旋转、透明度动画
  • 缓入缓出控制运动曲线
  • 贝塞尔曲线精细调整
  • 父子级联动画
  • 表达式驱动复杂动画

遮罩与抠像

  • 色度键：绿幕/蓝幕抠像
  • 亮度键：基于亮度抠像
  • 遮罩绘制：手动创建精确遮罩
  • 跟踪遮罩：跟随运动主体
  • 边缘优化：羽化、收缩、去边

🎨 调色艺术

色彩分级基础

一级调色 vs 二级调色

  • 一级调色：全局调整，影响整个画面
  • 二级调色：局部调整，针对特定颜色范围或区域
  • 先完成一级调色，再进行二级调色
  • 一级调色确保技术正确性，二级调色实现创意效果

色彩空间理解

  • Rec.709：标准动态范围，用于网络和电视
  • Rec.2020：超高清标准，更广色域
  • Log：平面曲线，保留最大动态范围
  • HLG：混合对数伽马，兼容SDR和HDR
  • PQ：感知量化，用于HDR内容

示波器使用

  • 波形图：显示亮度分布，避免过曝欠曝
  • 矢量图：显示色彩饱和度和色相
  • 直方图：显示整体曝光分布
  • 假色显示：直观显示曝光问题区域
  • 养成看示波器的习惯，不要只依赖肉眼判断

色彩理论应用

  • 色轮原理：理解色彩关系
  • 色彩心理学：不同色彩的情感联想
  • 色彩和谐：创建视觉舒适的配色
  • 色彩对比：突出重点元素
  • 建立个人色彩风格

肤色保护技巧

  • 使用肤色限定器精确选择肤色范围
  • 保持肤色自然，避免过度饱和
  • 不同人种肤色的处理差异
  • 光照条件对肤色的影响

LUTs 使用指南

技术 LUT vs 创意 LUT

  • 技术LUT：色彩空间转换，如Log转Rec.709
  • 创意LUT：风格化调色，如电影胶片模拟
  • 技术LUT应在调色初期应用
  • 创意LUT应在一级调色后应用
  • 避免叠加多个创意LUT造成色彩混乱

LUT 应用层级

  • 项目LUT：应用于整个项目
  • 片段LUT：应用于特定片段
  • 节点LUT：应用于特定调色节点
  • 根据工作流选择合适的应用层级
  • 保持LUT应用的一致性

自定义 LUT 制作

  1. 创建调色预设
  2. 导出为.cube或.3dl格式
  3. 在其他项目中复用
  4. 分享给团队成员
  5. 建立个人LUT库

LUT 强度调整

  • 大多数软件支持LUT强度控制
  • 通常30%-70%强度效果最佳
  • 避免100%强度造成过度处理
  • 根据素材特点调整强度
  • 混合多个LUT时注意强度叠加

不同场景 LUT 选择

  • 日景：明亮、高对比LUT
  • 夜景：低对比、冷色调LUT
  • 室内：暖色调、柔和LUT
