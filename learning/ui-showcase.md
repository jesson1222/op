## ⚡ 交互功能

### 搜索流程

```
1. 用户输入关键词
   ↓
2. 选择搜索引擎（可选）
   ↓
3. 点击搜索或按回车
   ↓
4. 显示加载动画
   ↓
5. 并行查询选中的引擎
   ↓
6. RRF 算法融合结果
   ↓
7. 去重处理
   ↓
8. 显示统计面板
   ↓
9. 显示搜索结果
```

### RRF 融合算法

```python
Score = Σ 1 / (k + rank), k=60

# 示例：
# Google #1: 1/(60+1) = 0.0164
# Bing #1: 1/(60+1) = 0.0164
# DuckDuckGo #3: 1/(60+3) = 0.0159
# 总分：0.0487
```

### 去重逻辑

```javascript
// 基于域名去重
const seen = new Set();
return results.filter(result => {
    const domain = new URL(result.url).hostname;
    if (seen.has(domain)) return false;
    seen.add(domain);
    return true;
});
```
