```json
  {"name": "gid", "value": "...", "domain": ".xiaohongshu.com"},
  {"name": "id_token", "value": "...", "domain": ".xiaohongshu.com"}

```

### 发布命令示例
```bash
mcporter call 'xiaohongshu.publish_content(
  title: "标题",
  content: "正文",
  images: ["/app/images/xxx.png"],
  tags: ["tag1", "tag2", "tag3"]
)'
```

### 注意事项
- 标题长度限制：约 20 字符
- 标签最多 10 个
- 图片必须在容器内路径（`/app/images/`）
- 每小时发布频率过高，建议 2-3 小时间隔
- 新号每天不超过 5 条

## 💡 经验教训

1. **小红书发布必须有图片**，纯文字无法发布
2. **图片路径问题**：Docker 容器需要复制图片到 `/app/images/`
3. **标题长度限制**：控制在 20 字符以内
4. **标签数量限制**：最多 10 个
5. **发布频率**：每小时太频繁，建议 2-3 小时
6. **Cookie 格式**：必须是 JSON 数组格式（Chrome DevTools Protocol）
