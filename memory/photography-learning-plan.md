## 💡 PetaPixel 40 条摄影技巧精选 (2026)

### 核心技巧 TOP 10

1. **靠近拍摄对象** - Robert Capa："如果你的照片不够好，是因为你靠得不够近"
2. **每天拍摄** - 大量练习，风格会自然形成
3. **观察光线** - 先观察再拍摄，注意光的方向和质量
4. **征得许可** - 拍摄人物时尊重对方，尤其是不同文化背景
5. **白天也用闪光灯** - 强光下用闪光灯填充阴影
6. **ISO 选择原则**：
   - 正午户外：ISO 100-200
   - 室内/黄昏：ISO 800-1600
   - 夜景手持：ISO 3200+
7. **f/4 万能光圈** - 长焦 + f/4 可以分离主体与背景
8. **讲笑话** - 比说"笑一个"能得到更自然的笑容
9. **买书不买器材** - 看大师作品比买设备更重要
10. **阅读说明书** - 了解你的相机所有功能

### 进阶技巧

- **慢下来思考** - 按快门前先构图、思考用光
- **停止回看** - 不要每拍一张就看屏幕，会错过精彩瞬间
- **框架式构图** - 用门窗、拱门引导视线
- **用光塑形** - 避免顺光（太平），尝试侧光、逆光
- **黄金时刻** - 日出后/日落前 1 小时拍人像和风景
- **保持简单** - 1-2 个兴趣点即可，不要杂乱
- **变换视角** - 蹲下、趴下、登高，避免"肚脐视角"
- **注意背景** - 避开垃圾桶、难看的墙、标志牌

### 职业建议

- **随身携带相机** - 手机也可以，关键是随时能拍
- **加入摄影社区** - 获得反馈，结交同好
- **用心拍摄** - 即使不拿相机也要练习观察
- **回馈被摄者** - 给人家打印照片作为回报
- **轻装上阵** - 1 机 2 镜比一堆设备更自由

## 📝 学习笔记

### 曝光三角速记
```
光圈 f 值越小 = 光圈越大 = 进光越多 = 景深越浅
快门数值越大 = 速度越快 = 进光越少 = 越能凝固瞬间
ISO 越高 = 越敏感 = 画质越差 = 噪点越多
```

### 安全快门公式
```
安全快门 = 1 / 等效焦距
例：50mm 镜头 → 1/50 秒
```

### 景深三要素
1. 光圈越大，景深越浅
2. 焦距越长，景深越浅
3. 距离越近，景深越浅
