# 📕 小红书自动发布工具

使用 Playwright 浏览器自动化发布小红书笔记。

---

## ⚠️ 重要提示

1. **封号风险**: 自动化操作可能违反小红书用户协议，请谨慎使用
2. **首次登录**: 第一次运行需要手动扫码登录
3. **登录态保存**: 登录信息保存在 `sessions/` 目录，注意保密
4. **发布频率**: 建议每天不超过 3-5 篇，模拟人工操作
5. **验证码**: 遇到验证码需要手动处理

---

```bash
# 已安装 Playwright，确保浏览器已安装
playwright install chromium
```

## 📖 使用流程

### 首次运行

1. **启动脚本**
   ```bash
   python3 publish_xiaohongshu.py
   ```

2. **浏览器打开** - 会弹出 Chromium 浏览器

3. **手动登录** - 有 60 秒时间完成登录
   - 扫码登录（推荐）
   - 或账号密码登录

4. **登录态保存** - 成功后自动保存，下次无需重复登录

5. **填写内容** - 脚本自动填写标题、正文、标签

6. **上传图片** - 如有图片会自动上传

7. **确认发布** - 30 秒倒计时后可手动或自动点击发布

### 后续运行

登录态保存后，直接运行即可自动发布：
```bash
python3 publish_xiaohongshu.py
```

## 🛠️ 故障排除

### 问题 1: 登录态失效

**症状**: 每次运行都需要重新登录

**解决**:
```bash
rm sessions/xiaohongshu_context.json
# 重新运行，手动登录
```

### 问题 2: 图片上传失败

**症状**: 提示找不到图片上传控件

**解决**:
- 检查图片路径是否正确
- 确保图片格式是 JPG/PNG
- 手动在浏览器中上传

### 问题 3: 页面元素找不到

**症状**: Selector timeout

**解决**:
- 小红书可能更新了页面结构
- 将 `headless=False` 查看实际页面
- 手动检查元素选择器

### 问题 4: 触发验证码

**症状**: 出现滑块验证码或短信验证

**解决**:
- 手动完成验证
- 降低发布频率
- 使用 `headless=False` 模式

## 📊 最佳实践

### 发布时间
- **工作日**: 18:00-21:00（晚高峰）
- **周末**: 10:00-12:00（上午悠闲）
- **避免**: 深夜 23:00-07:00

### 发布频率
- **新号**: 每天 1-2 篇
- **老号**: 每天 3-5 篇
- **间隔**: 至少 2 小时

### 内容策略
- **标题**: 20 字以内，包含关键词
- **正文**: 分段清晰，1000 字以内
- **标签**: 10-15 个，精准 + 长尾
- **图片**: 6-9 张，高质量

## 🙋 常见问题

**Q: 可以发布视频吗？**
A: 当前版本仅支持图文，视频发布需要额外处理。

**Q: 可以批量发布吗？**
A: 可以修改脚本循环发布，但强烈不建议（封号风险高）。

**Q: 登录态能保存多久？**
A: 通常 7-30 天，取决于小红书的安全策略。

**Q: 会被封号吗？**
A: 有 risiko。建议：
- 模拟人工操作（已实现）
- 控制发布频率
- 使用主账号谨慎测试
